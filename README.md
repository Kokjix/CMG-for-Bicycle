# CMG Stabilized Bicycle Simulation

This project investigates the stabilization of a bicycle using a **Control Moment Gyroscope (CMG)**. The bicycle is modeled as an **inverted pendulum**, and the gyroscopic torque generated by the CMG is used to maintain balance.

The system dynamics are derived using the **Euler–Lagrange method**, and the model is implemented and simulated in **MATLAB/Simulink**.

---

## Project Overview

Balancing a bicycle is a classical control problem. In this project, instead of using steering control or moving masses, stabilization is achieved using a **Control Moment Gyroscope (CMG)**.

A CMG produces torque through the interaction of:

* a high-speed rotating **flywheel**
* a rotating **gimbal axis**

When the gimbal rotates while the flywheel spins at constant speed, a **gyroscopic torque** is generated perpendicular to both axes. This torque is used to stabilize the bicycle.

---

## System Modeling

### Bicycle Model

The bicycle is modeled as an **inverted pendulum**.

State variable:

* θ → bicycle tilt angle relative to the vertical axis

Using the Euler–Lagrange formulation, the dynamic equation of the bicycle becomes:

θ̈ = (g · sin(θ) · k₂ − T_y) / k₁

Where:

* **T_y** → torque produced by the CMG
* **k₁, k₂** → system parameters derived from inertia and mass properties of the bicycle and gyroscope components
* **g** → gravitational acceleration

---

### Control Moment Gyroscope Model

The torque produced by the Control Moment Gyroscope is obtained from the gyroscopic coupling equation:

T_y = I_p · ω_p · ω_x

Where:

* **I_p** → flywheel inertia
* **ω_p** → flywheel angular velocity
* **ω_x** → gimbal angular velocity

This gyroscopic torque is applied to the bicycle model in order to counteract the gravitational torque and maintain balance.

## Simulation

The system is implemented in **MATLAB/Simulink**.

The main simulation model is:

final_model.slx

Simulation outputs such as bicycle angle, gyroscope motion, and generated torques can be analyzed using the **MATLAB Data Inspector**.

## Project Structure

CMG-for-Bicycle/

* final_model.slx → main simulation model
* gimbal.slx → gyroscope gimbal subsystem
* bicycle.slx → bicycle dynamic model
* gyro_and_bicycle_params.m → system parameter definitions

## How to Run the Simulation

1. Clone the repository

```
git clone https://github.com/Kokjix/CMG-for-Bicycle.git
```

2. Open MATLAB

3. Run the parameter script

gyro_and_bicycle_params.m

4. Open the main Simulink model

final_model.slx

5. Run the simulation and inspect signals using **Data Inspector**
